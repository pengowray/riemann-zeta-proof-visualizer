The Lean proof of the Riemann Hypothesis, as a treemap

On 20 November 2026 Levent Alpöge released a Lean 4 formalization, written with Claude, that states and proves the Riemann Hypothesis and its generalization to Dirichlet L-functions. The source is 175,187 modules (a module is one .lean file). This page shows what is in them.

The statement

Statements.lean defines the propositions and Main.lean proves them, and Mathlib's own RiemannHypothesis, by citing theorems from the other modules. The cleanup also has Challenge.lean, which states the same theorems with sorry in place of each proof so that a checker can compare the two files.

Main.lean proves the Riemann Hypothesis and the Generalized Riemann Hypothesis for Dirichlet L-functions as five theorems, using only Lean's three standard axioms (propext, Classical.choice and Quot.sound). Statements.lean states the five theorems in Mathlib's terms. Both editions of the rewrite also have Challenge.lean, which states the same five theorems with sorry in place of each proof, so that a checker can compare the two files.

Statements.lean defines four propositions. Main.lean proves them, and Mathlib's own RiemannHypothesis, by citing theorems from the other 175,185 modules.

In words: every zero of the Riemann zeta function, other than the trivial zeros −2, −4, −6, … , has real part ½. For every Dirichlet character χ, every zero of L(s, χ) with real part strictly between 0 and 1 has real part ½.

      If it were printed

      Long lines wrap onto the next line. Stack of paper: printed on both sides, on paper 0.1 mm thick. A4 listing: 80 characters by 60 lines a page, a 10-point monospaced font. Book page: 65 characters by 40 lines. Base64 is a way to write any file as text, using 4 characters for every 3 bytes.

          Who has checked the proof

          What each of these public pages reported when read on 23 November 2026. None of the checks were run in building this page.

          The Lean statements cover the Riemann zeta function and Dirichlet L-functions. They do not cover Dedekind zeta functions or automorphic L-functions.

          Sources and method

          • All counts on this page come from a script that reads every file once. Its totals match the independent checks above: 175,187 files, 17,374,215 lines, longest import chain 203.
          • Declarations are counted by matching keywords such as theorem and def at the start of a line. Lean's kernel checks more declarations (1,484,729 in the nanoda runs), because Lean generates auxiliary declarations.
          • The proof steps on the map follow jae-63's blueprint, which matched Alpöge's timeline to Lean names by search and partial reading. It is one reader's interpretation.

          Other maps and cleanups of the proof

          • riemannhypothesissolved.com: an interactive map of the files, grouped into 2,647 clusters in 63 themes, with guides to the proof at several levels.
          • An illustrated atlas (nasqret.github.io): the argument component by component, with each step linked to the Lean source and marked with what has been machine-checked.
          • Riemann Hypothesis proof diagrams (scottcochran.github.io): twenty zoomable posters of the theorem dependency graph, drawn from a blueprint of 416 statements.
          • RH proof size (rh-shrink.github.io): charts of how much the community cleanup has shrunk the source, updated every 15 minutes.
          • riemann.verifytask.cn: a separate public challenge to compress 158,055 of the files, 92% of the source, with each result checked by Lean.
